# 전환 내역

## 기준

원본 `Groupware` 저장소의 `main` 브랜치, 커밋 `ee188ed`를 기준으로 만들었습니다. 원본 폴더는 수정하지 않았습니다.

사용자가 승인한 방향은 기존 화면과 정상적인 기능을 유지하고, 명백한 오류는 수정해 별도로 기록하는 것입니다. 기존 DB의 실제 데이터는 가져오지 않고 새 전용 계정에 원본 기반 샘플 데이터를 구성했습니다.

## 기술 변경

| 원본 | 전환 |
|---|---|
| Java 8 / 외부 Tomcat 9 | Java 17 / Spring Boot 4.1.1 / 내장 Tomcat |
| HttpServlet·@WebServlet | Spring MVC Controller·요청 매핑 |
| 요청마다 new DAO | Spring이 생성·주입하는 DAO |
| DBConnection의 고정 연결 정보 | Spring DataSource와 로컬 설정·환경변수 |
| H2 Oracle 호환 모드 | 실제 Oracle 19c |
| H2 Java 백업 트리거 | Oracle PL/SQL 백업 트리거 |
| JSP 안에서 DB 조회·정렬·페이징 | DashboardService에서 준비하고 JSP는 출력 |
| 배포 폴더 안에 업로드 저장 | 프로젝트의 data/uploads/board에 저장 |
| AES 복호화와 평문 혼용 | BCrypt 검증, 샘플 평문의 최초 로그인 시 해시 전환 |

DTO, SQL 기반 DAO, JSP의 화면 구조와 CSS·이미지를 최대한 유지했습니다. JPA·React 등으로 구조를 바꾸지 않았습니다.

JSP 본체는 `WEB-INF/views`에 두고 기존 `.jsp` 주소는 MVC에서 연결합니다. `MvcServletConfig`는 공개 `.jsp` 주소와 내부 JSP 렌더링을 구분하기 위한 설정입니다. 기존 `.do` 주소도 유지합니다.

## 원본 문제와 수정

1. **관리자 자동 로그인**: `/main.do`가 테스트용 관리자 세션을 생성하던 코드를 제거했습니다. 로그인이 필요합니다.
2. **비밀번호 재설정**: 요청의 사번만 믿고 변경하던 경로를 제거했습니다. 사번·이름 확인 후 받은 세션이 있어야 하며 유효시간은 5분입니다. 로그인 상태에서 변경할 때는 현재 비밀번호도 검증합니다.
3. **사원 계정 활성화**: 사원 확인을 거친 세션에서만 미등록 계정을 활성화합니다. 이미 등록되었거나 퇴사한 계정의 비밀번호를 덮어쓰지 않습니다.
4. **관리·수정 권한**: 관리자 요청은 서버에서 권한을 확인합니다. 게시글 수정 POST, 댓글·파일 처리, 예약 확정·취소에도 필요한 권한과 소유자 검사를 추가했습니다.
5. **예약 중복**: 서로 다른 DAO 객체에 적용되던 synchronized를 대신해, 같은 회의실 행을 Oracle에서 잠그고 중복 확인과 선점을 한 트랜잭션으로 처리합니다.
6. **예약 유효시간·시간대**: 만료된 선점은 확정할 수 없습니다. Oracle 세션 시간대를 한국 시간으로 맞추고, 선점 시간을 세션의 LOCALTIMESTAMP로 계산합니다.
7. **중복 반려·반납**: 결재 문서를 잠그고 현재 상태를 확인합니다. 같은 요청으로 재고가 두 번 복구되지 않습니다. 퇴사자 대여는 관리자가 대리 반납할 수 있습니다.
8. **연차 중복 차감**: 최종 승인 시 현재 결재 단계와 잔여 연차를 확인하고 서명·상태·연차를 한 트랜잭션으로 변경합니다.
9. **관리자 권한 양도**: 복수 관리자에서 실패할 수 있는 단일행 서브쿼리를 정리하고, 권한 회수와 부여를 한 트랜잭션으로 처리합니다.
10. **상태값 혼용**: DB의 업무 상태는 기존 한국어 값으로 통일했습니다. 일본어 표시는 화면·메시지 파일에서 유지합니다.
11. **누락 화면**: 존재하지 않던 `findUser.jsp` 경로를 기존 비밀번호 찾기 화면에 연결했습니다.
12. **파일 저장**: 안전한 파일 이름과 별도 저장 위치를 사용합니다. 저장 실패 시 새 파일을 정리하고, 다른 게시글의 첨부파일을 삭제할 수 없게 했습니다.
13. **요청 토큰**: POST와 기존 GET 방식 삭제·반납·취소·로그아웃 요청에 세션 토큰을 확인합니다. 기존 폼·버튼에는 공통 스크립트가 토큰을 전달합니다.
14. **리소스·빌드**: 메시지 파일을 Maven 리소스 경로로 옮기고 기본 한국어 번들을 추가했습니다. Maven Wrapper와 UTF-8 설정을 포함했습니다.

## 데이터 구성

- 사원 25명, 회의실 11개, 비품 36종
- 게시글 30개, 댓글·답글 60개
- 회의실 예약 47개, 비품 대여 43개, 휴가 이력 34개
- 한국어·일본어 초기 데이터 중 하나를 선택
- 원본의 DATEADD 및 시퀀스 재시작 문법을 Oracle용으로 정리
- 재고와 잔여 연차를 이력에서 다시 계산해 샘플 값의 일관성 확보
- 원본에 실제 첨부파일이 없어, 없는 파일을 가리키던 더미 메타데이터 대신 실제 샘플 텍스트 파일 제공

실제 운영 데이터·업로드 파일을 원본에서 추출해 옮기는 작업은 이번 새 데이터 구성에 포함하지 않았습니다.
